# Bundled fonts

These files are self-hosted so the app keeps its typography under the strict
Content-Security-Policy (`font-src 'self' data:`), with no third-party requests.

| File | Family | Source |
| --- | --- | --- |
| `InstrumentSans-Variable.woff2` | Instrument Sans 400–700 | https://fonts.google.com/specimen/Instrument+Sans |
| `InstrumentSerif-Regular.woff2` | Instrument Serif 400 | https://fonts.google.com/specimen/Instrument+Serif |
| `IBMPlexMono-Regular.woff2` | IBM Plex Mono 400 | https://fonts.google.com/specimen/IBM+Plex+Mono |
| `IBMPlexMono-Medium.woff2` | IBM Plex Mono 500 | https://fonts.google.com/specimen/IBM+Plex+Mono |
| `IBMPlexMono-SemiBold.woff2` | IBM Plex Mono 600 | https://fonts.google.com/specimen/IBM+Plex+Mono |

`OFL.txt` for the full license text.
